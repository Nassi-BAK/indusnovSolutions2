## Instructions for Integration

### Step 1: Backup Current Files
```bash
# Make copies of your existing i18n files
cp src/i18n/en.json src/i18n/en.json.backup
cp src/i18n/fr.json src/i18n/fr.json.backup
```

### Step 2: Merge the JSON

**Option A: Manual Merge**
1. Open `src/i18n/en.json` in your editor
2. Find the closing `}` bracket at the end
3. Add a comma after the last existing section
4. Add all the new sections above
5. Repeat for `src/i18n/fr.json`

**Option B: Programmatic Merge**
Create a script using a JSON merge tool or use jq on command line:
```bash
# Using jq (requires installation)
jq -s add src/i18n/en.json new-keys-en.json > temp.json && mv temp.json src/i18n/en.json
```

### Step 3: Verify JSON Syntax
```bash
# Check if JSON is valid
node -e "console.log(JSON.parse(require('fs').readFileSync('src/i18n/en.json')))" 
node -e "console.log(JSON.parse(require('fs').readFileSync('src/i18n/fr.json')))"
```

### Step 4: Test in Your Application
1. Start the dev server: `npm run dev`
2. Switch languages and verify all content displays correctly
3. Open browser console and check for translation key warnings
4. Test each modified component

## Alternative: Create Separate Files

If you prefer to keep things modular, you can create separate i18n files:

**src/i18n/sections.en.json**
```json
{
  "predictiveMaintenanceSection": { ... },
  "chatbot": { ... },
  "serviceDetail": { ... },
  "contactInfo": { ... },
  "portfolio": { ... }
}
```

**src/i18n/sections.fr.json**
```json
{
  "predictiveMaintenanceSection": { ... },
  "chatbot": { ... },
  "serviceDetail": { ... },
  "contactInfo": { ... },
  "portfolio": { ... }
}
```

Then update `src/i18n/index.ts`:
```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

import fr from './fr.json';
import en from './en.json';
import ar from './ar.json';
import sectionsFr from './sections.fr.json';
import sectionsEn from './sections.en.json';

// Deep merge function
const deepMerge = (obj1, obj2) => {{ ... }};

const resources = {
  fr: { translation: deepMerge(fr, sectionsFr) },
  en: { translation: deepMerge(en, sectionsEn) },
  ar: { translation: ar },
};

i18n.use(initReactI18next).init({
  resources,
  lng: 'fr',
  fallbackLng: 'fr',
  interpolation: { escapeValue: false },
});

export default i18n;
```
